# Medical Insurance Cost Prediction

A beginner Machine Learning project that predicts medical insurance charges based on
factors such as age, BMI, smoking status, number of children, sex, and region.

## Dataset

The project uses the Medical Cost Personal Dataset (`insurance.csv`).

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## Steps Performed

- Data loading and exploration
- Data preprocessing
- Exploratory Data Analysis (EDA)
- Feature analysis
- Model training
- Model evaluation
- Medical insurance cost prediction

## Objective

To understand the basic Machine Learning workflow and build a model
for predicting medical insurance charges.
